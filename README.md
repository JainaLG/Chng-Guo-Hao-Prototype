# Chng Guohao / Wealth Path prototype

Figma plugin source for generating 1440px website frames that match the [Chng Guohao design file](https://www.figma.com/design/6OAG1NAK4POnb3m1Ynpsv8/Chng-Guo-Hao--FA--Website-Prototyping?node-id=0-1&m=dev), the [prototype navigation](https://www.figma.com/proto/6OAG1NAK4POnb3m1Ynpsv8/Chng-Guo-Hao--FA--Website-Prototyping?node-id=25-2090), and the Awaiken Fintech page structure.

The live plugin lives in the Figma account library. These files are a snapshot of that published plugin.

## What it generates

The panel’s primary action is **Generate page**. **Generate full sitemap** creates the six prototype routes in a row:

- Home
- About
- Estate Planning
- Retirement Planning
- Articles
- Book an Appointment

Pages use Figma style-guide tokens (navy, teal, gold, CTA green, Manrope ExtraBold, DM Sans), prototype destinations, and Fintech-style sections filled with copy from the design file. Portrait and photo slots are placeholders.

See [`figma-plugin/README.md`](figma-plugin/README.md) for the page-type table and source notes.
